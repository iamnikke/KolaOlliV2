# KolaOlliV2

***

## Backend käynnistys
Aja yhdessä terminaalissa tämä:

``
cd backend
python app.py
``

## Frontend käynnistys
Aja toisessa terminaalissa tämä:

``
cd frontend
python3 -m http.server 3000
``

## SQL käynnistys
``
mysql.server start 
``
